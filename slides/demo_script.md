# 実機デモの台本（約90秒）

スライド「実機デモ（約90秒）」のページで、ブラウザに切り替えて行う。
デモがうまく動かないときは、スライドに戻り「パレートフロント：読み方」「地図で見る両端」「What-if 分析」のページで同じ内容を説明する。

## 事前準備（発表の前に）

1. AMPL がある Mac でバックエンドを起動する（フロントはビルド済みのものを配信する）。

   ```sh
   cd optimization/multiobjective_app/frontend && npm run build
   cd ../backend && AMPL_DIR=/Applications/AMPL uv run --with-requirements requirements.txt uvicorn main:app --port 8000
   ```

2. ブラウザで http://localhost:8000/ を開き、計算が終わっていることを確認する（Mac では1秒以内）。
3. 画面はプロジェクターに合わせて 1280×720 以上にする。左上のシナリオが「なし／×1」になっていることを確認する（違えば「初期値に戻す」）。
4. スライドとブラウザをすぐ切り替えられるようにしておく。

## 手順と話すこと

| 時間 | 操作 | 話すこと |
|---|---|---|
| 0:00 | 画面全体を見せる | 「左が設定、真ん中がパレートフロント、右が地図です。主目的は平均所要日数、副目的は総輸送コストです」 |
| 0:10 | ε スライダーを左端（0）へ動かす | 「ε = 0 はコスト最小。地図は緑の鉄道が多く、平均5.32日かかります」 |
| 0:20 | スライダーを右端（1）へ動かす | 「ε = 1 は日数最短。すべてオレンジの道路になり2.50日、ただしコストは約38%高くなります」 |
| 0:30 | スライダーを 0.3 付近へ戻す | 「最初の少しの追加予算で日数が大きく縮みます。これが収穫逓減です」 |
| 0:40 | パレートフロントの点を1つクリック | 「点を選ぶと、その輸送計画が地図に出ます。白い点が運ぶ向き、線の太さが輸送量です」 |
| 0:55 | What-if で「Houston」にチェック | 「Houston 港がストライキで止まった場合です。貨物はほかの港へ振り替えて、自動で計算し直します」 |
| 1:05 | 結果と地図を指す | 「最小コストは約29%上がり、最短でも3.60日かかります。Houston は灰色になっています」 |
| 1:20 | 「元に戻す」を押す | 「同じモデルのまま、条件を変えて比べられます」→ スライドに戻る |

## 注意

- スライダーは計算済みの101点を表示するだけなので、待ち時間はない。
- What-if は、チェックしてから約0.6秒後に自動で計算する（Mac では計算自体は約0.2秒）。
- 地図の背景（OpenStreetMap）はインターネット接続が必要。つながらない場合も経路と点は表示される。
